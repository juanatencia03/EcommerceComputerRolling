# 🎮 Nexus PC - E-Commerce de Hardware y Periféricos

Nexus PC es una plataforma de comercio electrónico enfocado en la venta de **componentes de computación, periféricos y equipos informáticos de alto rendimiento**, desarrollada como proyecto grupal para RollingCode School.

🔗 **[Ver Demo](https://nexuscomputer.netlify.app/)**
